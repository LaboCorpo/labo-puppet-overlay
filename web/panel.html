    Troubleshooting

    Discord setup

    Advanced: Client Secret (only if “Public Client” is off)

    One-time setup (done by whoever manages the app)

    1. Open discord.com/developers/applications → New Application.
    2. OAuth2 tab: add the redirect http://localhost and turn on Public Client.
    3. App Testers tab: invite everyone who will run the app (max 50). Each must accept the invite. Friends who only appear in your channel don't need anything.
    4. Copy the Application ID above (or bake it into the build via the DISCORD_CLIENT_ID repo variable).

    On first connection Discord shows an authorization popup: click “Authorize”. It won't ask again.
