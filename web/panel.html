    Alert sounds

    Put your sounds (MP3, WAV, OGG) and pictures (GIF, PNG, JPG, WEBP) in the Son Twitch folder, then choose them below. Each sound can show a GIF on stream while it plays (in the Alerts OBS source).

    Add as many sounds as you like per event. Random never plays the same sound twice in a row, In order goes through the list, All together layers them. Add the Alerts (GIF + sound) source from Stream widgets to OBS to see the GIFs (and to hear the sounds there with “Played by OBS”).

    Friends' cams

    Send a link to a friend: they open it in their browser, choose their camera and click Start. Their camera then shows up in OBS, one Browser Source per friend or all together in one scene. The video goes straight from them to you (free VDO.Ninja service), nothing to install for them.

    All the cams in one scene

    Drag a camera to move it, drag its corner to resize it (Shift: free size). OBS follows.

    OBS links

    Each link is a Browser Source. Untick “Their sound in OBS” if you already get their voice another way (Discord…). With Control audio via OBS ticked on the source, each friend gets their own mixer slider.

    Security

    Every link carries a password: nobody can watch a camera without it. A new password cancels every link already sent (send the new ones).

    Discord bot
    
      
    Friends create their puppet in Discord, without installing anything: they type /puppet create, choose with menus and see the result live. Only one person runs the bot (the “host”): their LaboHub must be open.
    
      
    
        
        
    Status—
    
        
        
    
        
    
      
    
      
    Share the puppets with the crew
    
      
    
        
        
        
        
    
        
    Without a GitHub token, puppets made with the bot are saved on the host only (and each friend can still send their /puppet code). With it, they are added to the crew's shared file, which every LaboHub reads every 2 minutes. Tokens are stored encrypted on this PC.
    
      
    
      
    Set up the bot (once, by the host)
        
      
          
    1. On discord.com/developers/applications, open the LaboHub application (the one in Discord setup), then Bot → Reset Token, copy it and paste it above.
      2. 
          
    2. Still in Bot, no special intent is needed (leave the “Privileged Gateway Intents” off).
      3. 
          
    3. Click ➕ Invite the bot to a server and choose the Labo's server.
      4. 
          
    4. Tick Run the bot on this PC. In Discord, type /puppet create.
      5.

    Advanced: Client Secret (only if “Public Client” is off)
          
        
    
      
    
      
    
        
    One-time setup (done by whoever manages the app)
    
        
      
          
    1. Open discord.com/developers/applications → New Application.
      2. 
          
    2. OAuth2 tab: add the redirect http://localhost and turn on Public Client.
      3. 
          
    3. App Testers tab: invite everyone who will run the app (max 50). Each must accept the invite. Friends who only appear in your channel don't need anything.
      4. 
          
    4. Copy the Application ID above (or bake it into the build via the DISCORD_CLIENT_ID repo variable).
      5. 
        
    
        
    On first connection Discord shows an authorization popup: click “Authorize”. It won't ask again.
