**🎭 Puppet Overlay — les marionnettes du vocal**

Chaque personne du salon vocal s'affiche sur ton écran en marionnette de papier dont la tête s'ouvre quand elle parle.

**Avant de commencer**
Accepte l'invitation *App Tester* que je t'ai envoyée sur Discord (sinon l'app ne peut pas lire le vocal).

**Installation (2 min)**
1. Télécharge `PuppetOverlay-…-setup.exe` ici : <lien>
2. Windows affiche un écran bleu SmartScreen (l'app n'est pas signée) : **Informations complémentaires → Exécuter quand même**.
3. Garde l'application **Discord** ouverte (pas la version navigateur). Au premier lancement, clique sur **Autoriser** dans la fenêtre de Discord.
4. Suis le guide qui s'ouvre : il te fait créer ton avatar.
5. Clique sur **Partager mon avatar** et colle-moi le code ici. Je l'ajoute au fichier commun et ta marionnette apparaîtra chez tout le monde.

**Raccourcis**
- `Ctrl+Maj+O` : afficher / masquer l'overlay
- `Ctrl+Maj+P` : déplacer les marionnettes (souris, molette pour la taille, `Échap` pour terminer)
- `Ctrl+Maj+M` : couper le son du chat Twitch

**Bon à savoir**
- Fermer la fenêtre ne quitte pas l'app : elle reste dans la barre des tâches. Clic droit sur l'icône près de l'horloge → *Quitter*.
- En jeu, mets le jeu en **plein écran fenêtré** (le plein écran exclusif cache l'overlay).
- Les mises à jour s'installent toutes seules au redémarrage.
- Un souci ? **Réglages → Copier les diagnostics**, et colle-moi le résultat.
